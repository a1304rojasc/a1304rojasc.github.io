Reto 07: el mensaje escondido en el rojo

Una imagen de un atardecer, con los metadatos limpios y nada útil en strings. El informante insiste: «el mensaje está en los píxeles; en el rojo, en lo más pequeño».

Esteganografía LSB

La esteganografía no esconde el contenido del mensaje, como la criptografía, sino su existencia. En imágenes, la técnica clásica usa el bit menos significativo (LSB):

Rojo original:  200 = 1100100[0]
Con un bit 1:   201 = 1100100[1]   ← diferencia invisible al ojo

Cada píxel presta un bit, y cada 8 píxeles forman un carácter.

Paso a paso

Primero descarto lo fácil:

file atardecer.png                      # PNG 320x200, nada raro
strings atardecer.png | grep -i centinela  # nada

Luego extraigo el último bit del canal rojo, fila por fila:

from PIL import Image

img = Image.open("atardecer.png").convert("RGB")
ancho, alto = img.size
bits = [img.getpixel((x, y))[0] & 1 for y in range(alto) for x in range(ancho)]

mensaje = bytearray()
for i in range(0, len(bits), 8):
    byte = 0
    for bit in bits[i:i + 8]:       # el primer bit es el más significativo
        byte = (byte << 1) | bit
    if byte == 0:                   # byte 0 = fin del mensaje
        break
    mensaje.append(byte)

print(mensaje.decode())             # CENTINELA{…}

Herramientas como zsteg prueban todos los canales y órdenes de bits a la vez. Aquí la combinación ganadora es b1,r,msb,xy.

Lección

  • LSB sobrevive en PNG, que comprime sin pérdida, pero se destruye si la imagen se guarda como JPEG o si una red social la recomprime.
  • Se usa para marcas de agua, y también lo usa el malware para esconder órdenes dentro de imágenes inocentes.
