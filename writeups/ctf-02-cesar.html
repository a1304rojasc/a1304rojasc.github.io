Reto 02: César se rompe en 25 intentos

Un mensaje interceptado conserva espacios y puntuación, pero sus letras no tienen sentido. La pista dice que usa el método de Julio César: cada letra se desplaza k posiciones en el alfabeto.

Opción A: texto conocido

La última línea termina en NPYETYPWL{...}. Todas las flags tienen el formato CENTINELA{...}, así que ya sé cómo empieza el texto en claro:

N (13) − C (2) = 11
P (15) − E (4) = 11   ✔

La clave es 11. Para descifrar todo de una vez, resto 11 a cada letra con tr:

tr 'L-ZA-Kl-za-k' 'A-Za-z' < interceptado.txt

Opción B: fuerza bruta

Sin texto conocido también cae, porque solo hay 25 claves posibles:

def cesar(t, d):
    r = ""
    for c in t:
        if c.islower():   r += chr((ord(c) - 97 + d) % 26 + 97)
        elif c.isupper(): r += chr((ord(c) - 65 + d) % 26 + 65)
        else:             r += c
    return r

for d in range(1, 26):
    print(d, cesar(texto, -d).splitlines()[0])

Solo la línea del desplazamiento 11 es español legible: «Atacaremos al amanecer por el flanco norte». La flag es CENTINELA{…}.

Lección

Un cifrado con pocas claves se rompe probándolas todas. AES-128 tiene 2128 claves: aunque probaras mil millones por segundo, tardarías billones de veces la edad del universo.
