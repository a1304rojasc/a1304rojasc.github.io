Reto 03: Vigenère contra un ataque de texto conocido

El general del reto anterior se pasó a Vigenère, que durante casi 300 años se consideró «indescifrable»: cada letra se desplaza una cantidad distinta según una palabra clave que se repite. Su error fue poner la flag al principio del mensaje.

La idea

cifrada = (clara + clave) mod 26   →   clave = (cifrada − clara) mod 26

Si conozco un trozo del texto en claro, obtengo ese trozo de la clave directamente.

Recuperar la clave

El mensaje empieza por JEYVWALLL{, y en claro tiene que decir CENTINELA{:

CifradaJEYVWALLL
ClaraCENTINELA
ClaveHALCONHAL

Sale HALCONHAL: la palabra HALCON que vuelve a empezar. Esa es la clave.

Descifrar

clave = "HALCON"
r, i = "", 0
for c in texto:
    if c.isascii() and c.isalpha():
        base = 65 if c.isupper() else 97
        k = ord(clave[i % len(clave)]) - 65
        r += chr((ord(c) - base - k) % 26 + base)
        i += 1
    else:
        r += c

Ojo: el índice i solo avanza con las letras. Si avanzara también con los espacios, la clave se desalinearía. La flag es CENTINELA{…}.

Lección

Un cifrado moderno debe resistir ataques de texto conocido: aunque sepas parte del mensaje, no debes poder deducir la clave. Y los mensajes reales están llenos de texto predecible (cabeceras, saludos, formatos), que es justo lo que se usó contra Enigma.
